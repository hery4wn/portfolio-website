# Portfolio Hery

Website portfolio pribadi Heryawan, dibangun dengan Next.js, React, TypeScript, dan GSAP.

## Menjalankan secara lokal

Gunakan Node.js 22–24, lalu jalankan:

```sh
npm ci
npm run dev
```

Buka http://127.0.0.1:3100. Untuk memeriksa tipe dan membuat build produksi, jalankan `npm run check` dan `npm run build`.

Kode aplikasi berada di `src/`, sedangkan gambar, video, font, dan lisensi font berada di `public/`.
